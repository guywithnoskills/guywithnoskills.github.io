# malav.org

Malav Akhani's portfolio site — a Spotify-inspired, choose-your-own-path experience ("Recruiter" vs "Stalker") built with React, Vite, Tailwind, and Framer Motion.

Originally designed and built in [Figma Make](https://www.figma.com/make/), exported to plain React/Vite so it no longer depends on a Figma subscription to stay live.

## Running locally

```bash
npm install
npm run dev
```

## Deploying

Pushing to `main` builds the site and deploys it to GitHub Pages automatically (see `.github/workflows/deploy.yml`). The custom domain is configured via `public/CNAME`.
